# Acceptance rule: a rejected artefact stops the cascade (2026-10-21)

**Defect.** The paper states that an artefact which still fails its checks after the
repair budget "is rejected". The code only logged the failure: `_verify_and_repair`
returned, the stage finished, and the next stage consumed the artefact. The single-pass
arm had no gate at all. And the model-execution step, when given a notation with no
`package` declaration, substituted the file name as the package name and executed it,
so programs "executed" against notations the parser rejects.

**Fix.**
- `VerificationResult.rejected`: an artefact check (parse, structure, execution,
  refinement) still failing after repair. A trace-resolution failure alone is reported,
  not blocking. Unrunnable checks reject only under `verification.strict`.
- Every stage records `stage_status.json` (accepted / rejected, repair attempts, failures)
  and raises `StageRejected` on rejection; every stage refuses to start on a rejected
  upstream artefact; the sweep records later stages as not run.
- The single-pass arm now runs the same gate with no repair (`repair=False`).
- `convert_emfatic_to_ecore` refuses a package-less notation (`MissingPackageDeclaration`);
  the execution check reports that as a failure, not as unverifiable.
- Tests: `MALCOMp/tests/test_stage_rejection.py`.

Fisher exact, construction under the halt rule: single-pass vs cooperating p = 7.9e-11;
single-pass vs single + repair p = 3.7e-7; cooperating vs single + repair p = 0.57.

**What changes.** Nothing for the cooperating or single + repair arms: no rejected
artefact of theirs fed a later stage (the four rejected cooperating construction programs
were the last stage of their block). For the single-pass arm, every downstream figure
previously reported was measured on artefacts the pipeline now refuses to build on. The
behaviour-phase comparison between single-pass and cooperating therefore no longer exists:
the single-pass arm never reaches that phase. The single + repair arm was not run through
the behaviour phase, so there is no gated single-generator behaviour result.
